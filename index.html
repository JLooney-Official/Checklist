Checking

Checking notification status...

This app will check what your browser allows.

1. Enable

Tap Enable notifications and allow Chrome to send notifications for this site.

2. Test

Tap Send test. You should see a phone notification almost immediately.

3. Add reminders

Tasks need a due date, due time, and reminder setting to notify you.

4. Keep it installed

For best results, use the installed app icon and open it at least daily.

If notifications still do not work

  1. Make sure you opened the GitHub Pages HTTPS link, not a local file.
  2. In Chrome, tap the lock/site icon and allow notifications for the site.
  3. Check Android app notification settings for Chrome.
  4. Use the installed home-screen app instead of a normal browser tab.
  5. For timed reminders, keep the app open/recently active. Full always-on background push requires a server.
